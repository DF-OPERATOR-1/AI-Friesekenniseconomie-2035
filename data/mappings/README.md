# Beroepskoppelingen

`isco2008_brc2014.csv` bevat de gebruikte ISCO 2008–BRC 2014-koppeling uit het
CBS-schakelschema. Codes blijven tekst, inclusief voorloopnullen.

De CompetentNL-inhoud wordt rechtstreeks via de aangeleverde beroeps-URI’s en
ISCO-codes gekoppeld in `research/pipeline/imports/occupation_content.py`.
De website gebruikt geen naamvoorstellen of semantische kandidaatkoppelingen.

BRC 2014 is nog niet gevalideerd gekoppeld aan de BRC Plus-namen uit de UWV-bron.
Er worden daarom geen vacatureaantallen over ISCO-beroepsgroepen verdeeld.
